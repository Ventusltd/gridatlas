## Findings

**F1. The 60+3 contract is exact, fail-closed, and now proven on the real DOM.**
SH:142–261 declares 60 `ukConfig` layers (7+6+11+9+1+1+3+4+1+1+16). The engine builds one `data-layer-id` checkbox per layer in `#scada-ui-container` and a twin in `#fs-curtain-keys` (SI:1068–1093). Pipeline News appends a `.key-group[data-pn-group]` with 3 `data-pn-layer` checkboxes to both containers (SI:6597–6626, 6672–6676). The menu bar's `inventory()` (SI:4456–4477) counts only `#scada-ui-container input[type=checkbox][data-layer-id|data-pn-layer]` and requires `engine===60 && pipeline===3 && total===63 && unique===63` (constants SI:4381–4383); `required()` adds `'63 unique layer controls'` to `missing` (SI:4506); `install()` returns false while anything is missing (SI:5998–6005); `start()` retries 160×250 ms then `loudFailure()` paints the red `#gridatlas-menu-bar-failure` banner and leaves the raw v8 UI (SI:6106–6152). Live counts, all three viewports (`.final.json`): SCADA 60/3 (63 checkboxes + 2 basemap radios), curtain 60/3, Grid 63 proxies (60 engine + 3 pipeline), document 120 + 6, `inspect() = {60,3,63,63,complete:true}`, `tries` 3–8, no page errors. Real-DOM gate (`.failclosed.json`, injected ≤4.4 s after load, before PN/menu installed): a 61st `data-layer-id="uk_lightning"` → `installed:false`, 160 tries, banner "expected 60 engine + 3 Pipeline News layer controls; found 61 + 3. Original controls remain available.", no bar, `.map-controls` back to `display:flex`, brand not fused (`G-failclosed-engine61.png`); a 4th `data-pn-layer` → same with "found 60 + 4"; the identical control with NEITHER attribute → menu installs (tries 5), 63 proxies, and a real click on it leaves `engine_checked 0, pn_checked 0`, no errors. Originals stayed hittable and working in every variant (`dc` → `[OK]`, curtain twin mirrored, `l-dc` visible).

**F2. Event path a native-looking checkbox must take (code + browser proof).**
Engine delegated `change` on both containers acts only on `e.target.dataset.layerId` or `name="bm"/"bm-fs"` (SI:1095–1115); PN acts only on `dataset.pnLayer` (SI:6631); the menu's document `change` listener syncs only keys from `layerKey()` = `data-layer-id`/`data-pn-layer` (SI:4428–4434, 6077–6080). So an input with none of these is inert to all three owners — measured: real click on the appended probe in SCADA and curtain changed nothing (`probe_native_append.after_click`, `curtain_append.probe_click`). Consequences: (a) the Grid dropdown will NOT proxy it — `buildLayerControls` runs once at install (SI:6009) and the MutationObserver only re-runs `adoptLate`+`syncAll` (SI:6093–6099); the addon must add and sync its own Grid row. (b) Inside the bar, a click on any INPUT/BUTTON lacking `data-gridatlas-layer-proxy` (and not `.gm-title`/`type=text`) closes every menu on the next tick (SI:6069–6074) — proven: probe row without the attribute → panel `hidden:true`; with `data-gridatlas-layer-proxy="weather:probe"` → stays open, matching the original layers' "menu stays open" semantics (SI:6091) and contrasting the basemap radios, which close by design (SI:5828–5831; measured `basemap_sat_closes`). (c) The addon must never forward with `.click()` on a twin: the document click closer fires for clicks outside the bar unless the closure-private `forwardingLayerChoice` is set (SI:4413, 5806–5808, 6065–6068) — set `.checked` on twins and dispatch/handle `change` instead (code-derived, not browser-tested). (d) Keyboard: ArrowDown on Grid opens the panel and focuses the first `button,input,[role=button]` (SI:4921–4927) — measured `engine:400`, Space toggles the original and keeps the panel open, Escape closes and refocuses the title. Any weather row placed BEFORE the body changes that first focus.

**F3. Insertion point: append after PIPELINE NEWS moves nothing; prepend moves all 63.**
`.scada-keys` and `#fs-curtain-keys` are 2-column CSS grids, 1 column ≤480 px (CSS:17, 127, 130–131). PN's own precedent is `container.appendChild(group)` (SI:6624). Scroll-independent measurement (`.geometry.json`, `.curtain.json`): appended `.key-group` → 0/63 originals moved in SCADA at 1440/393/360, 0/63 in the curtain at desktop, 393, 360 and iOS emulation, 0/63 proxies; it lands as grid item 14 (desktop: row 7 col 2 beside PIPELINE NEWS, rect [726,1795,697,98]; phones: bottom row). Prepended (WM:104) → 63/63 moved everywhere (desktop columns swap: `engine:400 [14,18]→[723,18]`; phones +56 px every row). Grid dropdown body (`column-count` 3/2/auto, SI:4629–4633): append moves 19/63 proxies at 1440 (multicol rebalance, REPD column −22 px), 0 on phones; prepend moves 44 (desktop) / 63 (phones); a new flex child after `.gm-panel-body` ("footer") or in `.gm-panel-head` moves 0 proxies within the body but shrinks the body's visible height (512→428/441 px desktop, 698→614/627 px at 393). No placement is pixel-identical with Grid OPEN; Grid is closed at rest (SI:6084, 4869).

## Objections to other lanes
- Visual parity: at-rest screenshots cannot see the Grid dropdown, the curtain or the collapsed phone panel; compare proxy/checkbox rects with Grid open and with LAYERS opened, and do not treat the Chromium-granted-fullscreen curtain as a regression (F5a).
- Baseline architect / builder: the loader accepts only `replace-script` slots (atlas/index.html:61–63, 74–79); four of five shell script tags are consumed (SH:135–139); only the CDN `maplibre-gl.js` tag (SH:133) is free. A "single additive cartridge" therefore needs either that slot (carrying MapLibre bytes) or a versioned derivative of an existing cartridge; `run-current.mjs:31–37` also demands `tools/proofs/<generation>-<id>.proof.mjs` per composed cartridge.
- Transport: the control must exist with a `[WAIT]/[FAIL]/[EMPTY]` label before any data arrives (PN precedent `[SELECT A PROJECT]`, SI:6571–6575), never gated on `isStyleLoaded()`; add no source/layer while OFF.
- Regression auditor: browser proofs wait for `>=60` proxies (all-controls:29, all-layer-clicks:33); none asserts 63 against the composed page, so a 64th marker is invisible to them — add an explicit count.
- Time-window UX: any `<input>` (date, number) inside the Grid panel without `data-gridatlas-layer-proxy` closes the menu on click (SI:6069–6074); a `<select>` does not; controls placed before the body steal ArrowDown focus (F2d).

## Recommendation for the smallest additive integration
One module, PN-shaped (SI:6666–6724), installed only after `menuBar.installed && __GRIDATLAS_PIPELINE_LAYERS__.installed`, OFF by default, no `ukConfig`, no `window.fetch` patch, no `data-layer-id`/`data-pn-layer`/`lbl-*`/`name="bm"`:
1. `#scada-ui-container` and `#fs-curtain-keys`: `appendChild` one `.key-group` (`.key-title` "WEATHER (EUMETSAT LI)", one `.key-item` with `<input type=checkbox data-weather-layer="uk_lightning">` and a `data-weather-label` span) — 0/63 originals move, iOS fullscreen covered.
2. Grid dropdown: one `.gm-layer-group` + `.gm-layer` row (`.gm-layer-box`, `.gm-layer-name`) in a new flex child after `.gm-panel-body` (before `#fs-curtain-tab`); input carries `data-gridatlas-layer-proxy="weather:uk_lightning"` so the panel stays open (document the 64-marker count in proofs); ArrowDown still lands on `engine:400`.
3. One delegated `change` listener per container keyed on `dataset.weatherLayer`; sync by setting `.checked` on the three twins, never `.click()`; labels only in its own spans; source/layer added on first ON; states WAIT/LOAD/OK n/EMPTY/STALE/FAIL with the period text.
4. Hit-tested proofs (Playwright, no force): per viewport 1440x900 / 393x852 / 360x740 (+390x844 iOS-emulated): arrival counts 60/3/63 and `inspect().complete`; phone: real tap on `#gridatlas-dash-toggle`, then `elementFromPoint` + real tap on `data-layer-id="400"`, `"dc"`, `"caes"`, `data-pn-layer="all"` and the weather input after `scrollIntoViewIfNeeded`; Grid: real click/tap on the title, on `engine:dc` (panel stays open, original+curtain mirror), on the weather row (panel stays open, three twins agree), on a basemap radio (closes); keyboard ArrowDown/Space/Escape on desktop; fullscreen via View→⛶ then Grid→⬇ Layers on the iOS path, tap the curtain weather twin; deep link `?technology=solar&latitude=…` on both phones with the sheet open: `elementFromPoint` on the toggle, GRID/SUBS chips and Grid proxies must resolve to themselves; content-relative rects of all 63 originals before/after the implant must be identical on SCADA, curtain and Grid body.

## Verdict
PASS for the original 60+3 contract and its semantics (proven live and fail-closed on the real DOM); the rejected preview FAILS the menu contract in spirit (prepend moved all 63 originals, borrowed private markers, proof enforced the shift). Lightning can coexist only as an appended, attribute-free native row plus a self-synced Grid row in a footer slot — BLOCKED_DEPENDENCY/HARNESS only for CDN hosts and WebKit, both worked around with hash-verified local bytes and labelled emulation.
