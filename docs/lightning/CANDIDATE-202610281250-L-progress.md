## The 257,654 vs 364,980 discrepancy
grid.py:20 defines each cell as `[cell, day, n, day, n, …]`.
- L-style summed only the first `(day, n)` pair of each cell, which gives 257,654.
- Summing every pair gives 364,980, which equals the index and the files' `total`. I re-checked this on origin/main 6109e0e.
- L-perf was right. The module uses K's gg/gd parser, which reads every pair.

## What changed (on top of J + the L-engine cell tap)
1. **Grid fetching above the cap.** This is K's loader taken verbatim:
   - `GS` schema constant, regex-gated month path, the 140×120×0.1 checks, per-day sums and sha256 arrays.
   - A day counts only when its coverage, count and sha256 match the index row. Stale days are named as "not yet in the grid".
   - On 404 or invalid data, the caption falls back to J's summary with "cell grid archive not yet published / unavailable: …".
   - The grid is fetched before the LOAD POINTS consent gate. Windows within the cap make no grid request.
2. **Cell circles in the L-style spec.** No heatmap.
   - Source `gridatlas-lightning-cells`. Layers `…-cell-glow` (blur 1, filter n ≥ max(3, p90)), `…-cell-core` (sort-key n, 0.8 px ink stroke) and `gridatlas-lightning-cell`, the invisible 22 px hit layer that L-engine's tap queries.
   - Violet ramp `#eef0ff → #c6b4ff → #9a5cff → #c21cff` on log10(n), with stops at n = 1/10/100/≈316.
   - Radius is interpolated over zoom 5/7/10: 1.6–7, 3–11 and 5–22 px.
   - No id starts with `l-`, so the original's armed point tool never fires twice.
   - The layers are inserted below the first `src-repd` layer, so projects stay on top. If there is none, they go below our points.
   - The order seen in the browser: cell-glow, cell-core, cell, l-solar, l-gridatlas-lightning.
   - style-spec 19.3.3 validation finds 0 errors (`tools/validate-style.mjs`, `out/cell-layers.json`).
3. **Land / near-shore clip, client-side.** The bytes fit, so no grid.py change was needed. This follows the lead's decision.
   - The mask is L-perf's: a cell centre within 30 km of an onshore REPD site.
   - I re-encoded it as a run-length string of 497 chars (letter prefix for runs ≥ 36, no separators), against L-perf's 801. The round-trip is exact. It is built by `tools/mask.mjs` and decoded lazily (`LM`).

4. **Taps.**
