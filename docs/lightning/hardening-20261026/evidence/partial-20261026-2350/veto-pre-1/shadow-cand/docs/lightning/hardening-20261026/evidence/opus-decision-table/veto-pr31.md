## Objections to other lanes

- Visual parity: at-rest phone screenshots prove nothing (Finding 9). Capture Grid, Layers panel and curtain open; diff DOM order, not just pixels; mask the canvas; never compare across harnesses.
- Menu contracts: document-wide counts of `[data-gridatlas-layer-proxy]` or `input[data-layer-id]` (the shim's `waitForComposition` reports 120) are not the contract; use `menuBar.inspect()` and `#scada-ui-container` scope; flag proxy impersonation.
- Transport: the shim answers with `access-control-allow-origin: *`, so CORS is unproven locally; one live request must be witnessed. Route-mocking the feed as `uk-lightning-preview.browser.mjs` line 48 did is not a real response.
- Time-window UX: 12m/6m/3m options with no archive invite "0 flashes" lies (V9).
- Builder: never wrap `initVentusMap` (the 202610221600 mistake); ship `<generation>-sld-sandbox.proof.mjs`.

## Recommendation for the smallest additive integration

One new generation of the sld-sandbox cartridge (the slot whose own doctrine is to extend rather than claim a slot, current.json line 256): original 435,218 bytes unchanged, plus one appended, self-contained lightning module that waits for `menuBar.installed`, adds ONE control where the owner specifies (recommend the native `#scada-ui-container` row at the END of the panel, never prepended, mirrored into `#fs-curtain-keys` by the same path the engine uses), carries no engine/proxy attributes, fetches the live `.geojson` by XMLHttpRequest and PR #1 `.json` shards by fetch, renders a single MapLibre circle layer OFF by default, and prints the V8 label. No composer change, no bridge change, no preview loader, no ukConfig mutation. Composition manifest, current.json and STATE.md change only in a separate owner-approved release PR.

### Task 5 — three most likely cheats or errors to forbid in the plan

1. **Proxy impersonation / count inflation**: adding `data-gridatlas-layer-proxy` (or a Grid-panel row) to keep the dropdown open, so proof counts of 60+ "pass" while the contract is breached (weather-module.js line 57).
2. **Route-mocked "real network"**: fulfilling the feed with a fixture (preview proof line 48) or pointing the shim's `lightningDataDir` at a synthetic directory and reporting it as live data, or routing a `.geojson` URL to hide the bridge hijack instead of changing transport.
3. **Prepend-and-wrap**: injecting the control at the top of a panel or the Grid body (shifting every original row, as the preview did), or wrapping `initVentusMap`/ukConfig as 202610221600 did — both are visually "different" the moment a surface is opened even though at-rest phone pixels match.
