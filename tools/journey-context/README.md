# GJ-04 official planning context preview

This is a partial GJ-04 source-context increment, separate from Pipeline News
versions and from a real circuit/geometry crosswalk. It appends a compact,
removable details view inside the existing Journey panel. The native GIS,
frozen GJ-03 runtime, operative pointer, STATE, shell and existing cartridges
remain unchanged. This module draws no source, layer, line or arrow.

The only real input is Agent A's committed Pipeline producer export
for one Sea Link planning consent notice, supported by two government HTML
documents. The exact `acceptedNotice` consumer is reused unchanged. There is
no new government extractor, collector, source scheduler or independent fact
approval mechanism. A committed `producer-pin.json` and byte-exact producer
inputs are required before this build can produce real output. Source-pin
identity and actual approval references must be reviewed independently; a hash
does not authenticate a reviewer or itself grant rights.

## Ownership and delivery

Generation `202611171600` adds cartridge `grid-journey-official-context` after
the frozen `grid-journey-preview` cartridge. Its new script budget is proposed
for preview engineering only: 16,000 bytes, with a separate 8,000-byte local
JSON input cap and a 24,000-byte combined cap. These are not owner release
budget approval or the Offtakers allowance. All generated bytes are hashed in
the new composition; the JSON input also has an explicit hash and length.

The input is one local, immutable delivery asset, copied byte-exact from the
named producer commit. It is not a live government fetch. Delivery checks HTTP
status, header size, streamed byte limit, exact whole-artifact SHA256, strict
UTF-8 and then the unchanged producer admission model. Transport is aborted
after four seconds or on module/native map removal. Missing, changed,
unreviewed or oversized inputs display WITHHELD.

The explicit extension contract is the public DOM ID
`#gridatlas-gj03-panel`, inside `#map-container`. This closure owns both the
frozen provider and additive consumer. No private card closure is patched.
One MutationObserver watches only the native map container's direct children
for Journey root mounting/removal. The consumer replaces its own details on
Journey remount, disconnects on removal and never creates a competing panel.
The public module registry API is
`window.__GRIDATLAS_MODULES__.gridJourneyOfficialContext`, exposing `mount`,
`close`, `snapshot` and `destroy`. Native map removal cancels input work and
disconnects the observer.

## Reproduce

```text
node tools/journey-context/build.mjs --check
node --test tools/journey-context/context.test.mjs tools/journey-context/producer.test.mjs
node tools/proofs/202611171600-grid-journey-official-context.proof.mjs

npm ci
npx playwright install chromium
node tools/journey-context/browser.test.mjs
```

To assemble uncommitted preview output, omit `--check`. The builder needs only
this checkout and Node built-ins. It never reads adjacent worktrees. Serve it
with `node tools/journey-context/serve.mjs 8084` and open
`http://127.0.0.1:8084/atlas/v/202611171600/`.

The native browser proof runs the existing composer and MapLibre instance,
touch/keyboard controls at 390/393/1440 widths and landscape, actual source
delivery, scoped-context removal, Journey remount/coexistence and fail-closed
missing/changed/oversized local inputs. Synthetic node tests exercise display
and lifecycle negatives; they do not confer real-source approval. Every run
uses a new output directory and records errors/request failures separately.
Local receipts are kept under `receipts/`. Physical device acceptance and
hosted exact-head CI remain separate states.

## Rights, coverage and remaining gates

Only narrow government-authored facts are used under the stated GOV.UK OGL v3
footer, with independent exact-fact review references supplied by Agent A and
Agent B. Images, logos, linked submissions, unreviewed document bodies and
third-party material are excluded. The licence endpoint returned HTTP403 in
the source review; that access limitation does not become blanket reuse
approval. Visible document/event dates retain DAY precision; retrieval remains
an explicit UTC instant and source update time remains unknown unless supplied.

One documentary planning example does not complete the original GJ-04 regional
DNO/TO geometry programme. Real circuit identities, geometry/rights acceptance,
regional coverage and GJ-05 qualified flow context remain separate work. This
module creates zero REPD/ETYS joins or real routes. Physical handset, Safari,
VoiceOver and other assistive-technology acceptance remain unknown. A future
promotion requires the GridAtlas owner's separate release decision.

Remove this preview from a future composition by omitting its cartridge and
input references; call its public `destroy()` for runtime removal. Preserve
published historical preview bytes. There is no live pointer changed by this
increment and no production rollback to perform here.
