# Native Grid Journeys source

Bounded source import from GridAtlas commit 0cf8680d421f2cb659aa9924291c211466394490, with native Layers integration and public controller hooks for the overnight Atlas successor. Existing engine blobs and fixture provenance remain pinned in vendor-pin.json. This source change does not publish a generation.

## Interfaces

- assembleModule({generation}) from build.mjs returns {body,pin,fixture}; the integrator creates the new cartridge record and immutable composition. The 72,000-byte source cap is a proposed engineering limit within Atlas's existing 500,000-byte gate, not a recorded owner acceptance.
- window.__GRIDATLAS_MODULES__.gridJourneyPreview exposes mount(map), open({origin}), setOrigin(origin), snapshot() and destroy(). Both native Layers groups open the same controller as the map launcher.
- gridatlas:journey-open accepts detail={origin}. Origin uses {id,name,at:[longitude,latitude],type}; type may be repd, datacentre or substation. Context alone never seeds a circuit.
- Explore real grid nearby delegates to gridVicinity.open({origin,radiusKm:10}). Without coordinates, vicinity must ask for an origin; no route is invented. Invalid/null-island coordinates are not forwarded.
- The vicinity module alone consumes the journey=vicinity URL contract. This module does not consume URL parameters.

## Evidence and lifecycle

Real asset selection clears the synthetic demonstration and its owned layers. Exact circuit identity, reviewed geometry and rights are still required for a circuit itinerary. The optional explicit synthetic demonstration retains branch/backtrack, schematic and unlocated evidence distinctions. Its learning cursor never claims measured current, flow or a real connection.

Layers controls are installed into scada-ui-container and fs-curtain-keys, including containers arriving late. Closing restores the invoking launcher's focus. Destroy disconnects the observer and removes only owned controls, sources and layers.
